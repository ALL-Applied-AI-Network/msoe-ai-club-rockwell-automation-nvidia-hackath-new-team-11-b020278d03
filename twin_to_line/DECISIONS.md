# Team Ignite — Decisions

Durable engineering decisions. Change one only when new evidence contradicts it; then mark it superseded and add a new ID.

| ID | Decision | Reason | Date |
| --- | --- | --- | --- |
| D001 | Stay on Dataset 1 (Final Vial Inspection). | Twin + camera match the real station; switching costs more than it gains. Dataset 2 scored close (78 vs 92) but loses on switching cost. | 2026-10-13 |
| D002 | The product is commissioning / changeover speed, not "AI crooked-cap detection". Claim: the twin eliminates or sharply reduces the real defect data and line time needed to commission inspection. | Cap presence/tilt checks are commodity (Keyence, Cognex). Cutting real defect collection per changeover is not. | 2026-10-13 |
| D003 | Primary experiment is synthetic-only training (zero real images). Zero is the best possible result, not a hard requirement. | Measures the strongest version of the claim first. Organizers allow real data (Tanner, Oct 13: "up to you"), so this is our choice. See D014. | 2026-10-13 |
| D004 | Initial scope is the Good fixture, G01–G30. | Escapes in G are the costly failure. The twin has no S hole map (only 5 scrap vials lying down). | 2026-10-13 |
| D005 | Target visible crooked caps of roughly ≥15–20°. | Twin geometry: cap edge moves ~2 px at 10°, ~3 px at 15°, ~4–4.5 px at 20°, ~7 px at 30° (cap ≈ 21 px wide). | 2026-10-13 |
| D006 | Subtle tilt (<~15°) and lifted-but-level caps are reported as a camera-resolution limit, not a target. | Lifted 5 mm = 0.3 px. A seated cap on a 2°-leaning vial moves 2.3 px, more than a 10° tilt. Needs a side view. | 2026-10-13 |
| D007 | Fill-sequence reasoning is core: an empty hole inside the placed prefix = missed placement; after it = waiting. | Single-frame checks cannot tell these apart; twin numbering G01–G30 already equals fill order. | 2026-10-13 |
| D008 | Cosmos / VLM is optional; it must earn its cost by rescuing uncertain cases measurably. | Throughput is low but VLMs are slow/costly and not needed for the core states. | 2026-10-13 |
| D009 | Do not generate a dataset or train before the Isaac Sim appearance gate (kit gate-v2.0). | Geometry is proven; appearance transfer is not. | 2026-10-13 |
| D010 | No personal Brev spending before official team access. | Team credits come via the organizers' captain link; the gate does not change the team plan. | 2026-10-13 |
| D011 | Real-data boundary. **Runs 1–3**: development/reference — visual inspection, sim-to-real comparison, sanity checks, auto-labeling review, and adaptation ONLY if D014 is triggered. **Runs 4–5**: model holdout — never used for classifier training, threshold tuning, prompt examples, augmentation decisions, choosing the synthetic-data recipe, or choosing a model because it does better on these runs. Some run 4–5 frames were used in the Oct 13 geometry registration, so they are a valid model holdout but not a pristine end-to-end evaluation. **New CSI deliberate-defect collection**: preferred final end-to-end evaluation; any adaptation subset from it is chosen in advance and kept physically/logically separate. Evaluation unit = placement event, not frame. | Frames ~2 s apart are near-duplicates; a run-level split prevents tuning on the test set. | 2026-10-13 |
| D012 | Defect authoring = small USD override layers over the untouched station file; labels are derived by re-reading the composed stage. | Reproducible, tiny (≈5 KB per scene), labels cannot drift from the scene. | 2026-10-13 |
| D013 | Liquid = a simple colored cylinder inside the vial (UsdPreviewSurface, opacity 0.85), no fluid sim. | From overhead, a capped vial hides the liquid; an uncapped vial reads as a dark grey-green top in real frames. | 2026-10-13 |
| D014 | If synthetic-only falls short, run a controlled data-efficiency experiment: add labeled real subsets from runs 1–3 of 5, 10 and 20 examples, chosen in advance and nested (each larger set contains the smaller), to the synthetic training; evaluate each on the same holdout; report performance vs. number of real examples. | Turns the fallback into the headline curve ("how much real data the twin saves") instead of optimizing for a slogan. Tanner (Oct 13) confirmed any data mix is allowed. | 2026-10-13 |
| D015 | Twin USD geometry is the dimensional source of truth for vials, caps and fixtures. | Tanner (Oct 13): dimensions are preserved in the USD geometry, units and transforms. Our 3 px registration agrees. | 2026-10-13 |
| D016 | Real data request = a small hand-staged defect set on one filled G fixture (known tilt angles ~15/20/30°, missing caps, mid-sequence empties, all-good), not robot-filled runs. | Same evaluation value at a fraction of CSI line time; known angles also confirm the camera's crooked-cap limit. | 2026-10-13 |
