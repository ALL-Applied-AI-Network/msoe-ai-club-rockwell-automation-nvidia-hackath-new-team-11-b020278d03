## Architecture
Commissioning (GPU): twin files → position map at cap-top height (`capsealcam.py`) → Replicator defect renders (USD
overrides) → automatic labels → ResNet-18 crop classifier (primary learned model). The deterministic CV rule is the
baseline. TAO Visual ChangeNet is an optional comparison only. Cosmos and Nemotron are not dependencies (D008, D030).
Runtime (laptop): cap_seal frame → arm-clear check → 30 crops → visual state → fill-order reasoning from occupancy
(+ optional tracker, D021) → PASS / DEFECT / MISSED / WAITING / UNSURE operator map. No PLC connection.
